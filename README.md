# 多 Agent 狼人杀实验室

本科毕业设计项目：以狼人杀为环境，研究多 Agent 的协同与对抗。后端使用 Java 21 和 Spring Boot，前端使用 Vue 3、TypeScript 和 Vite。

## 已实现功能

- 独立于前端和 AI 接口的狼人杀规则引擎；默认 7 人局，也可配置 3–20 人及狼人、村民、预言家、女巫人数。
- RandomAgent、RuleAgent，以及可配置 Base URL、API Key 和 Model 的 OpenAI-Compatible LLM Agent。
- AI 对局逐人、逐阶段手动推进；展示公共事件、回放和仅供用户查看的身份及私有信息。
- 浏览器会话隔离对局；模型密钥仅在后端使用。
- 实验记录本地持久化、跨电脑 JSON 导入、重启后历史和时间线回放；固定种子的 Random / Rule 批量运行（每批 1–200 局）、进度与停止控制，以及 JSON / 对局 CSV / 行动 CSV 导出。
- 本地角色策略知识库：通用及四个角色分类，可添加、编辑、启停、导入导出；AI 对局按角色与阶段读取冻结快照，观战和存档展示实际使用条目。
- 实验名称、分组与备注；按模型、身份配置、知识模式和版本筛选记录；两组描述性对照、样本回放及汇总 CSV / JSON 导出。

## 本地运行

需要 Java 21、Node.js 20.19+ 或 22.12+、npm。在两个终端分别运行：

```powershell
cd backend
.\mvnw.cmd spring-boot:run
```

```powershell
cd frontend
npm install
npm run dev
```

打开 `http://127.0.0.1:5173`。不配置模型也能使用 RandomAgent 或 RuleAgent 完成对局。后端测试运行 `cd backend; .\mvnw.cmd test`，前端构建运行 `cd frontend; npm run build`。

## 项目结构

- `backend/src/main/java/com/example/werewolf`：规则引擎、Agent、模型客户端及 REST 接口。
- `backend/src/test`：规则、手动推进、模型解析和接口安全测试。
- `frontend/src`：对局设置、观战、回放、历史及统计页面。
- [`多Agent狼人杀毕业设计_初期任务规划.md`](./多Agent狼人杀毕业设计_初期任务规划.md)：需求、规则与后续实验规划。

在侧栏打开“实验记录”，可配置并运行基线批次；普通对局也会自动留存实验证据。开发模式默认写入固定的 `backend/data/experiments`（已被 Git 忽略），不受启动工作目录影响。打包运行时默认写入 jar 所在目录的 `data/experiments`，也可通过环境变量 `WEREWOLF_DATA_DIR` 指定绝对目录。页面显示实际保存位置。

同一浏览器在后端重启后仍可查看实验记录、对局历史和存档回放。换电脑时，在原电脑“导出完整 JSON”，在新电脑“实验记录 → 导入 JSON 记录”，即可查看统计和时间线回放，无须配置模型或 API Key。导入保存为独立副本，不覆盖原记录；导入副本不计入本机运行总览。进行中的游戏状态仍在内存中，重启会中断对局，但已保存的过程可回放。详见 [实验记录与批量运行说明](./docs/实验记录与批量运行.md)。

长期 Memory、狼人私聊、数据库、WebSocket 和显著性分析尚未实现。LLM 对局继续由用户手动推进。

## 本地知识库

侧栏“本地知识库”可查看示例策略并添加自己的建议。在总览配置 LLM Agent 后，选择“关闭策略知识”“仅通用知识”或“通用 + 对应角色知识”。默认关闭，方便建立实验基线；随机和规则 Agent 不使用知识库。

知识默认保存在 `backend/data/knowledge/knowledge.json`，打包后位于 jar 所在目录的 `data/knowledge`；可通过 `WEREWOLF_KNOWLEDGE_DIR` 指定目录。知识库由本机浏览器共享，编辑只影响新对局。导入知识 JSON 会追加新编号并保留本机内容；导入实验 JSON 仅供回放，不会安装其中的知识。详见 [本地知识库说明](./docs/本地知识库.md)。

## 实验分组与对照

总览创建普通或 AI 对局时，可填写实验名称、分组和备注；批量实验也支持这些标签。已有记录在“实验记录 → 编辑实验标签”中整理，标签随本地存档、完整 JSON 导出与导入保留。

侧栏“对照分析”分别设置 A、B 条件，点击生成分析，比较胜率、好人投票命中率、非法回复、纠错重试、耗时和模型用量。默认使用本机记录，每组按对局编号去重，只有完成局计入指标。可导出汇总 CSV 和分析 JSON；后者用于保留分析条件与汇总，不作为对局回放导入文件。详见 [实验分组与对照分析说明](./docs/实验分组与对照分析.md)。
